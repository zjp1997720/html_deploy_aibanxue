交互式课件“描述提示词”精简契约版（数学 + 物理，生成 {{String1}} 专用）

目的：让“描述生成模型”输出短小、可机读、可控长度的课件描述，供“代码生成提示词”引用为 {{String1}}。本提示词不涉及任何前端库/CDN/实现细节，只产出教学与交互规格。

使用方式（重要）
- 若用户信息不足：先输出最多 3 条澄清问题（Q1..Q3），停止。得到回答后再产出“描述”。
- 若信息充分：严格按“输出格式”产出；不要包含 Markdown 代码围栏、不要输出任何解释、不要输出示例代码。

输出格式（严格遵循）
1) 先输出一段 JSON（机读契约，见 Schema）
2) 紧接一个以 --NOTES-- 开头的中文要点段（≤ 300 字），用于教师阅览的精炼解释。

示例结构（仅示意）：
{ ...JSON... }
--NOTES--
要点1；要点2；要点3。

JSON Schema（键名固定，顺序建议）
- meta: { title, topic, grade, language }
- objectives: string[] 学习目标（3–5 条，短句，≤ 20 字/条）
- parameters: { name, symbol, unit, type, min, max, step, default, role }[]（≤ 6）
- relations: { formula, inputs[], outputs[], note }[]（≤ 5）
- visuals: { type: chart|geometry, series[], axes?, sampling? }[]（≤ 2）
- interactions: { target, binds[], effect }[]（≤ 6）
- complexity: tiny|small|standard（限制控件/系列/文本上限）
- constraints: { threeD: false, noCodeHints: true, language: zh-CN }

生成规则（MUST / MUST NOT）
- MUST：先 JSON 后 --NOTES--；参数含 unit/default 与范围；chart 建议 sampling.count=361；effect 用短语义（如 recompute:updateChart）。
- MUST NOT：任何库名/CDN/实现词；任何三维；任何代码/围栏；任何 on* 字样。

  "parameters": [
    { "name": "振幅", "symbol": "a", "unit": "", "type": "number", "min": 0, "max": 2, "step": 0.01, "default": 1, "role": "control" },
    { "name": "频率", "symbol": "f", "unit": "Hz", "type": "number", "min": 0.1, "max": 5, "step": 0.1, "default": 1, "role": "control" },
    { "name": "周期", "symbol": "T", "unit": "rad", "type": "number", "min": 0, "max": 1000, "step": 0.01, "default": 6.283, "role": "derived" }
  ],
  "relations": [
    { "formula": "y = a·sin(f·x)", "inputs": ["a","f","x"], "outputs": ["y"], "note": "x 以弧度计；T = 2π/f" }

    { "target": "slider", "binds": ["a"], "effect": "recompute:updateChart" },

调节振幅与频率，观察图像纵向拉伸与周期变化；强调 T=2π/f 的对应关系；示例范围适合课堂快闪演示。

few-shot 正例（物理）
JSON：
{
  "meta": { "title": "简谐振动", "topic": "弹簧-质点系统", "grade": "高二", "language": "zh-CN" },
  "objectives": ["识别周期", "理解参数关联", "读图判断状态"],
  "parameters": [
    { "name": "质量", "symbol": "m", "unit": "kg", "type": "number", "min": 0.1, "max": 5, "step": 0.1, "default": 1, "role": "control" },
    { "name": "弹性系数", "symbol": "k", "unit": "N/m", "type": "number", "min": 1, "max": 50, "step": 1, "default": 10, "role": "control" },
    { "name": "角频率", "symbol": "ω", "unit": "rad/s", "type": "number", "min": 0, "max": 20, "step": 0.01, "default": 3.162, "role": "derived" }
  ],
  "relations": [ { "formula": "x(t) = A·sin(ωt)", "inputs": ["A","ω","t"], "outputs": ["x"], "note": "ω = sqrt(k/m)；A 取 1" } ],
  "visuals": [ { "type": "chart", "series": ["x(t)"], "axes": { "x": "s", "y": "m" }, "sampling": { "count": 181 } } ],
  "interactions": [
    { "target": "slider", "binds": ["m"], "effect": "recompute:updateChart" },
    { "target": "slider", "binds": ["k"], "effect": "recompute:updateChart" }
  ],
  "complexity": "small",
  "constraints": { "threeD": false, "noCodeHints": true, "language": "zh-CN" }
}
--NOTES--
突出 m 与 k 对 ω 的影响；通过曲线读出周期与相位特征；控制项维持不超过 2–4 个，确保 60fps 课堂演示流畅。

校验锚点（便于自动验收）
- JSON 必含键：meta/objectives/parameters/relations/visuals/interactions/complexity/constraints
- parameters[].role 只能为 control 或 derived；每个参数均须 unit/default
- 计数上限：parameters≤6，relations≤5，visuals≤2，interactions≤6
- 长度上限：JSON≤约 800 字符；--NOTES-- ≤ 300 字
- 禁止出现：任何库名/CDN/实现术语；三维；代码围栏；on* 字样

物理交互课件“描述提示词”精简契约版（生成 {{String1}} 专用）

目的：驱动“描述生成模型”输出短小、可机读、可控长度的物理课件描述，供“代码生成提示词”当作 {{String1}} 使用。不得包含任何实现/前端术语。

使用方式
- 若信息不足：先仅输出至多 3 条澄清问题（Q1..Q3），停止；得到回答后再产出描述。
- 若信息充分：严格按“输出格式”产出；不要输出 Markdown 代码围栏/解释/示例代码。

输出格式（严格遵循）
1) 先输出一段 JSON（见 Schema）
2) 紧接一段以 --NOTES-- 开头的中文要点（≤ 300 字）

示例结构：
{ ...JSON... }
--NOTES--
要点1；要点2；要点3。

JSON Schema（键名固定）
- meta: { title, topic, grade, language }
- objectives: string[]（3–5 条，短句，≤ 20 字/条）
- parameters: object[]（≤ 6）
  - { name, symbol, unit, type, min, max, step, default, role }
  - type: number|integer|boolean|enum
  - role: control|derived（control 可调，derived 派生仅显示）
  - 每个参数必须包含 unit 与 default；数值需提供 min/max/step
- relations: object[]（≤ 5）
  - { formula, inputs[], outputs[], note }
- visuals: object[]（≤ 2）
  - { type: chart|geometry, series[], axes?, sampling? }
- interactions: object[]（≤ 6）
  - { target: slider|input|toggle|drag, binds[], effect }
- complexity: tiny|small|standard
- constraints: { threeD: false, noCodeHints: true, language: zh-CN }

MUST / MUST NOT
- MUST：先 JSON 后 --NOTES--；参数含 unit/default 与范围；chart 建议 sampling.count=181；effect 用短语义（如 recompute:updateChart）。
- MUST NOT：库/CDN/实现词（Chart.js/Canvas/DOM/JS/CSS 等）；三维；代码围栏；任意 on* 字样。

few-shot 正例（物理）
JSON：
{
  "meta": { "title": "简谐振动", "topic": "弹簧-质点系统", "grade": "高二", "language": "zh-CN" },
  "objectives": ["识别周期", "理解参数关联", "读图判断状态"],
  "parameters": [
    { "name": "质量", "symbol": "m", "unit": "kg", "type": "number", "min": 0.1, "max": 5, "step": 0.1, "default": 1, "role": "control" },
    { "name": "弹性系数", "symbol": "k", "unit": "N/m", "type": "number", "min": 1, "max": 50, "step": 1, "default": 10, "role": "control" },
    { "name": "角频率", "symbol": "ω", "unit": "rad/s", "type": "number", "min": 0, "max": 20, "step": 0.01, "default": 3.162, "role": "derived" }
  ],
  "relations": [ { "formula": "x(t) = A·sin(ωt)", "inputs": ["A","ω","t"], "outputs": ["x"], "note": "ω = sqrt(k/m)；A 取 1" } ],
  "visuals": [ { "type": "chart", "series": ["x(t)"], "axes": { "x": "s", "y": "m" }, "sampling": { "count": 181 } } ],
  "interactions": [
    { "target": "slider", "binds": ["m"], "effect": "recompute:updateChart" },
    { "target": "slider", "binds": ["k"], "effect": "recompute:updateChart" }
  ],
  "complexity": "small",
  "constraints": { "threeD": false, "noCodeHints": true, "language": "zh-CN" }
}
--NOTES--
突出 m 与 k 对 ω 的影响；通过曲线读出周期与相位特征；控制项维持不超过 2–4 个，确保课堂演示流畅。

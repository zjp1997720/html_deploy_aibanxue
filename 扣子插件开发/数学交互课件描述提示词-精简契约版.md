数学交互课件“描述提示词”精简契约版（生成 {{String1}} 专用）

目的：驱动“描述生成模型”输出短小、可机读、可控长度的数学课件描述，供“代码生成提示词”当作 {{String1}} 使用。不得包含任何实现/前端相关术语。

使用方式
- 若信息不足：先仅输出至多 3 条澄清问题（Q1..Q3），停止；得到回答后再产出描述。
- 若信息充分：严格按“输出格式”产出；不要输出 Markdown 代码围栏/解释/示例代码。

输出格式（严格遵循）
1) 先输出一段 JSON（见 Schema）
2) 紧接一段以 --NOTES-- 开头的中文要点（≤ 300 字）

示例结构：
{ ...JSON... }
--NOTES--
要点1；要点2；要点3。

JSON Schema（键名固定）
- meta: { title, topic, grade, language }
- objectives: string[]（3–5 条，短句，≤ 20 字/条）
- parameters: object[]（≤ 6）
  - { name, symbol, unit, type, min, max, step, default, role }
  - type: number|integer|boolean|enum
  - role: control|derived（control 可调，derived 派生仅显示）
  - 每个参数必须包含 unit 与 default；数值需提供 min/max/step
- relations: object[]（≤ 5）
  - { formula, inputs[], outputs[], note }
- visuals: object[]（≤ 2）
  - { type: chart|geometry, series[], axes?, sampling? }
- interactions: object[]（≤ 6）
  - { target: slider|input|toggle|drag, binds[], effect }
- complexity: tiny|small|standard
- constraints: { threeD: false, noCodeHints: true, language: zh-CN }

MUST / MUST NOT
- MUST：先 JSON 后 --NOTES--；参数含 unit/default 与范围；chart 建议 sampling.count=361；effect 用短语义（如 recompute:updateChart）。
- MUST NOT：库/CDN/实现词（Chart.js/Bootstrap/Canvas/DOM/JS/CSS 等）；三维；代码围栏；任意 on* 字样。

few-shot 正例（数学）
JSON：
{
  "meta": { "title": "正弦函数图像", "topic": "三角函数-正弦", "grade": "高一", "language": "zh-CN" },
  "objectives": ["理解振幅与频率", "读图判别周期", "连接代数与图形"],
  "parameters": [
    { "name": "振幅", "symbol": "a", "unit": "", "type": "number", "min": 0, "max": 2, "step": 0.01, "default": 1, "role": "control" },
    { "name": "频率", "symbol": "f", "unit": "Hz", "type": "number", "min": 0.1, "max": 5, "step": 0.1, "default": 1, "role": "control" },
    { "name": "周期", "symbol": "T", "unit": "rad", "type": "number", "min": 0, "max": 1000, "step": 0.01, "default": 6.283, "role": "derived" }
  ],
  "relations": [ { "formula": "y = a·sin(f·x)", "inputs": ["a","f","x"], "outputs": ["y"], "note": "x 以弧度计；T = 2π/f" } ],
  "visuals": [ { "type": "chart", "series": ["sin"], "axes": { "x": "deg", "y": "value" }, "sampling": { "count": 361 } } ],
  "interactions": [
    { "target": "slider", "binds": ["a"], "effect": "recompute:updateChart" },
    { "target": "slider", "binds": ["f"], "effect": "recompute:updateChart" }
  ],
  "complexity": "small",
  "constraints": { "threeD": false, "noCodeHints": true, "language": "zh-CN" }
}
--NOTES--
调节振幅与频率，观察图像纵向拉伸与周期变化；强调 T=2π/f 的对应关系；示例范围适合课堂快闪演示。

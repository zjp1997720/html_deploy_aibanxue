用户给你的数学交互课件的描述如下
一元二次函数图像与性质交互式课件提示词
课件目标

创建一个面向高中生的交互式课件，通过动态调整参数直观展示一元二次函数图像的变化规律，帮助理解参数 a、b、c 对函数图像的影响及相关数学性质。
核心数学概念

一元二次函数标准形式：y = ax² + bx + c (a ≠ 0)
图像特征：抛物线
关键性质：开口方向、顶点坐标、对称轴、单调性、最值、与坐标轴交点
交互设计要求
1. 参数调控区（左侧面板）

二次项系数 a：
滑块范围：-5 至 5（步长 0.1）
输入框：精确数值输入
显示当前 a 值及其含义说明
一次项系数 b：
滑块范围：-10 至 10（步长 0.5）
输入框：精确数值输入
显示当前 b 值及其含义说明
常数项 c：
滑块范围：-10 至 10（步长 0.5）
输入框：精确数值输入
显示当前 c 值及其含义说明
辅助选项：
复选框：显示 / 隐藏对称轴
复选框：显示 / 隐藏顶点
复选框：显示 / 隐藏与坐标轴交点
按钮：重置为默认值（a=1, b=0, c=0）
2. 可视化区（右侧面板）

坐标系：标准直角坐标系，x 轴范围 - 10 至 10，y 轴范围 - 20 至 20
函数图像：根据当前 a,b,c 值实时绘制抛物线
动态标记：
顶点标记：(h,k)，显示坐标值
对称轴：虚线表示 x=h
与 y 轴交点：(0,c)
与 x 轴交点：当 Δ≥0 时显示，标记坐标值
数值显示：
顶点坐标 (h,k)
对称轴方程 x=h
判别式 Δ=b²-4ac
开口方向（向上 / 向下）
当 Δ≥0 时显示方程 ax²+bx+c=0 的根
3. 知识讲解区（底部面板）

定义：一元二次函数的标准形式及 a≠0 的原因
参数影响说明：
a 的作用：开口方向和宽窄程度（a>0 向上，a<0 向下；|a | 越大开口越窄）
b 的作用：对称轴位置（h=-b/(2a)）
c 的作用：与 y 轴交点（0,c）
性质总结：
单调性：当 a>0 时，x<h 时递减，x>h 时递增；当 a<0 时相反
最值：当 a>0 时，y_min=k；当 a<0 时，y_max=k
与 x 轴交点情况：Δ>0 有两个交点，Δ=0 有一个交点，Δ<0 无交点
例题演示：提供 1-2 个典型例题，展示如何利用参数分析和解决问题
交互逻辑要求

所有参数调整后，图像和数值需实时更新（延迟不超过 0.5 秒）
当 a=0 时，自动提示 "a 不能为 0，这将不是二次函数"
当 Δ<0 时，明确说明 "函数与 x 轴无交点"
